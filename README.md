# Boules de Pétanque

Shopify front-end project built with Liquid, JavaScript, HTML and CSS.

Live website: https://boulesdepetanque-fr.com

## About the project

Boules de Pétanque is a Shopify store based on the Horizon theme that I worked on and customized for the needs of the store.

My work focused on the storefront, custom sections and the presentation of the products and content.

## What I worked on

Custom Liquid sections  
Homepage customization  
Buying guide section  
Product recommendation section  
Customer reviews section  
Brand story section  
Reassurance section  
Related product section  
Responsive layouts  
Theme customization

## Technologies

Liquid  
JavaScript  
HTML5  
CSS3
